## 1. Инструменты для работы: Node.js и npm

Для разработки современных веб-приложений код исполняется не только в браузере, но и требует предварительной сборки или загрузки пакетов.

* **Node.js** — программная платформа, позволяющая выполнять JavaScript-код на компьютере.
* **Npm** — пакетный менеджер для фронтенда. С его помощью в проект устанавливаются внешние библиотеки (например, Bootstrap).

**Инициализация проекта:**
При создании проекта выполняется команда `npm init`, которая создает файл `package.json`. Все устанавливаемые библиотеки помещаются в папку `node_modules`, которая исключается из системы контроля версий с помощью файла `.gitignore`.

## 2. Архитектура проекта и компоненты

Для того чтобы не писать весь код в одном файле `main.js`, проект разделен на логические блоки:
* **Страницы (`pages`)** — крупные блоки (например, главная страница со списком и страница отдельного продукта).
* **Компоненты (`components`)** — переиспользуемые мелкие блоки (карточки, кнопки, навигация).

Каждый компонент представляет собой класс. Пример базовой структуры страницы:
```javascript
export class MainPage {
    constructor(parent) {
        this.parent = parent; // Корневой элемент, куда будет рендериться страница
    }

    getHTML() {
        return `<div id="main-page" class="d-flex flex-wrap"></div>`;
    }

    render() {
        this.parent.innerHTML = ''; // Очистка контейнера
        this.parent.insertAdjacentHTML('beforeend', this.getHTML());
    }
}
```

## 3. Программирование логики рендера

Разберем, как отрисовываются карточки на странице на основе массива данных.

### Шаг 1: Получение данных (Mock-объекты)
Вместо реального бэкенда используются локальные данные:
```javascript
getData() {
    return [
        { id: 1, title: "Рубли", src: "img/rub.jpg" },
        { id: 2, title: "Доллары", src: "img/usd.jpg" }
    ];
}
```

### Шаг 2: Верстка компонента карточки
Метод `getHTML` принимает данные и подставляет их в строку с помощью шаблонных литералов:
```javascript
getHTML(data) {
    return `
        <div class="card" style="width: 300px;">
            <img class="card-img-top" src="${data.src}" alt="картинка">
            <div class="card-body">
                <h5 class="card-title">${data.title}</h5>
                <button class="btn btn-primary" id="click-card-${data.id}" data-id="${data.id}">Подробнее</button>
                <button class="btn btn-danger" data-delete-id="${data.id}">Удалить</button>
            </div>
        </div>
    `;
}
```

### Шаг 3: Отрисовка списка
В методе `render` главной страницы мы проходимся по массиву данных и для каждого элемента создаем экземпляр компонента карточки:
```javascript
const data = this.getData();
data.forEach((item) => {
    const productCard = new ProductCardComponent(this.pageRoot);
    // Передаем данные и функцию-обработчик клика
    productCard.render(item, this.clickCard.bind(this));
});
```

## 4. Настройка переходов между страницами (Роутинг)

В приложении реализован клиентский роутинг (SPA). При нажатии на кнопку "Подробнее" страница не перезагружается, а динамически подменяется ее содержимое.

### Обработка клика по карточке:
```javascript
clickCard(e) {
    // Получаем ID карточки из атрибута data-id
    const cardId = e.target.dataset.id;

    // Создаем экземпляр новой страницы и передаем ей ID
    const productPage = new ProductPage(this.parent, cardId);
    productPage.render();
}
```
Для возврата обратно используется кнопка "Домой" (HeaderComponent), которая очищает DOM и заново вызывает метод `render()` главной страницы.

## 5. Выполнение заданий по варианту (Дополнения V ATM)

В рамках индивидуального задания базовый функционал отображения был расширен функциями модификации данных.

* **5.1. Кнопка добавления карточки:** На страницу добавлена логика копирования первой карточки. При клике на кнопку добавления берется объект `this.data[0]`, ему присваивается новый сгенерированный ID, после чего объект добавляется в конец массива данных, и вызывается перерисовка страницы.
* **5.2. Удаление карточки:** К каждой карточке добавлена кнопка "Удалить" с атрибутом `data-delete-id`. При клике срабатывает обработчик, который фильтрует исходный массив `this.data = this.data.filter(item => item.id != deleteId)`, удаляя выбранный элемент, после чего интерфейс обновляется.
